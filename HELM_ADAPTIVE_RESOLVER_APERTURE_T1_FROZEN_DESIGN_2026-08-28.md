## 1. Executive summary

T1 asks whether HELM can reduce execution burden by deterministically selecting among execution paths that are already authorized and sufficient for the current governed snapshot. It does not let a model select authority, infer coupling, waive a Gate, or expose undeclared context.

The experiment compares three contemporaneous arms on a new, sealed 240-task corpus: unchanged HELM (H0), the same HELM with Adaptive Resolver Aperture v1 (H1), and a competent broad-context baseline (B). H1 may succeed only if every hard governance gate remains zero, correctness is non-inferior to H0 against sealed ground truth, and its burden reduction is both statistically and materially demonstrated against H0. Even then, the conclusion is limited to a candidate implementation mechanism.

## 5. NND corrections incorporated

### 5.1 No coupling inference

Only current, valid governed structure may declare a joint evidence surface. `Gate.required_evidence` is authoritative when present and valid. Models, classifiers, ratios, lexical rules, heuristics, learned policies, and runtime observations cannot establish coupling.

Absent, incomplete, stale, inconsistent, unavailable, invalid, expired, or unauthorized required evidence prohibits adaptive wide aperture. No partial coupled Payload or heuristic widening is allowed.

### 5.2 Coupling ratio is telemetry only

Where computable, the ratio `count(Gate.required_evidence) / count(relevant_available_evidence)` is recorded with `telemetry_only = true`. It cannot select a mode, authorize exposure, change a Gate, establish materiality, trigger or suppress Probe, or mutate state. No threshold is frozen.

### 5.3 Stateless selection

Every eligibility result is a pure deterministic function of the current governed snapshot and frozen configuration. Controller memory, learned policy, prior mode, prior economics, prior provider performance, task category, benchmark outcome, and reinforcement signals are prohibited.

Canonical history may participate only when it is governed state in the current snapshot: valid Decisions, graduated structures, lineage, validity and invalidation conditions, lifecycle position, and versioned authoritative evidence.

### 5.4 Exact adversary distribution

The complete 40-task steering-adversary distribution is frozen in §10. It may not be rebalanced after H1 implementation.

### 5.5 Non-generative hidden authority

The authority interface performs only exact hash-bound schedule lookup. No exact entry means `null`. It cannot generate, simulate, infer, interpolate, repair, or expose future human authority.

## 6. Candidate modes

### Mode A — Deterministic reuse / bypass

Eligible only when a reusable governed result is unambiguously established and identity, lineage, scope, versions, `valid_while`, and `invalidated_by` checks all pass, with no conflict or relevant authority/lifecycle change. Any ambiguity makes Mode A ineligible.

### Mode B — Sparse aperture

Uses the existing minimum-sufficient projection only where current governed contracts explicitly permit decomposable or sequential resolution. Decomposability is not inferred.

### Mode C — Wide governed aperture

Eligible only when the current valid Gate and version explicitly declare a complete, valid, authorized, conflict-free, and deterministically constructible `required_evidence` set. The Payload contains exactly that set—never the whole Slice, Domain Pack, Canonical state, neighbors, or inferred relations.

### Mode D — Full governed examination

Required for conflict, relevant invalidation, stale evidence, authority uncertainty, lifecycle transition, consequential rejection, conflicting authority, required human examination, incomplete eligibility, or steering ambiguity. Cost cannot downgrade this mode.

### Mode E — Probe / discovery

Used only when deterministic governed structure cannot establish a potentially material relationship and existing Probe eligibility applies. Probe remains DISCOVER / WAKE only.

## 7. Deterministic precedence

Precedence is evaluated without a model:

1. Conflict, invalidation, authority, lifecycle, or human-Gate protections select Mode D.
2. Unknown semantic relationships that meet existing Probe conditions select Mode E.
3. Unambiguous valid governed reuse selects Mode A.
4. An explicit, current, complete Gate-declared joint surface selects Mode C.
5. Explicitly governed decomposable/sequential resolution selects Mode B.
6. Missing, invalid, inconsistent, or ambiguous eligibility fails closed to Mode D.

Economics is not an eligibility input. It may compare only paths already established as equally authorized and sufficient.
